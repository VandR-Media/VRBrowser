# V&R Browser 0.3.1 — диагностическая сборка

- Утверждённая неоновая иконка подключена через mipmap.
- Добавлена отдельная иконка запуска «V&R Диагностика» для чтения локального отчёта после падения.
- Добавлен перехват необработанных Java/Kotlin-исключений; нативные падения WebView и системные принудительные остановки могут не попасть в отчёт.
- WebView запускается в защищённом блоке, чтобы показать ошибку при сбое инициализации.
- Версия увеличена до 0.3.1; package name не менялся.

## Загрузка с телефона

Самый простой вариант — создать в GitHub новую ветку, загрузить в неё содержимое обновлённого архива и открыть Pull Request в main. Если GitHub с телефона не позволяет загрузить каталоги целиком, понадобится загрузка через мобильный Git-клиент либо веб-редактор github.dev (для бинарных PNG потребуется отдельная загрузка). Не загружайте ZIP как единственный файл.

## После установки

Если браузер снова закроется, запустите «V&R Диагностика» (второй ярлык), нажмите «Скопировать отчёт» и пришлите текст. Отчёт может содержать адреса сайтов и технические пути — проверьте перед отправкой.

ВНИМАНИЕ: код не компилировался и не тестировался на Huawei. Это диагностическая сборка, а не исправление подтверждённой первопричины.
